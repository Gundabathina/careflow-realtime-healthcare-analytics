# CareFlow Analytics - additional Python packages installed into the

# see docker-compose.yml's airflow services and docs/airflow_orchestration_guide.md).
#
# This is NOT installed into the host's main Python 3.14 environment, and
# is NOT the same as .venv-dbt -- it lets DAG tasks running *inside* the

#   - requirements.txt (project runtime deps, for scripts/*.py)
#   - dbt-core/dbt-postgres pins from the Phase 3C .venv-dbt setup
#
# Consumed via the AIRFLOW_COMMON_PIP_ADDITIONAL_REQUIREMENTS environment
# variable in docker-compose.yml (see the x-airflow-common anchor) --
# a supported Airflow quickstart mechanism for local/dev use. For a
# production deployment, replace this with a custom Dockerfile that
# `pip install`s this file into a proper image layer instead (faster
# container start, immutable image, no dependency re-resolution on
# every restart).
