## Detailed version (for a LinkedIn article / project page)

CareFlow Analytics simulates the analytics platform a hospital system's
data team would actually build, end to end:

**Pipeline:** Synthea generates synthetic patients and their full
clinical history. Data moves through profiling and validation, then a
Bronze (typed Parquet, quality-gated) -> Silver (standardized) -> Gold
(dimensional star schema) transformation pipeline, each layer using
checksum-based incremental processing so unchanged data is never
reprocessed.

**Warehouse:** Gold loads transactionally into PostgreSQL -- 8
dimensions, 8 facts, 6 pre-aggregated marts -- validated by 172
automated checks comparing the live warehouse back to Gold's own
output.

**Analytics engineering:** A dbt layer (36 models, 133 tests) sits on
top, independently recomputing key business logic like patient
readmissions in SQL and reconciling it against the Python
implementation -- so a bug in either one gets caught by a test, not a
stakeholder.

**Orchestration:** Two Apache Airflow DAGs -- a parameterized full
pipeline run and a scheduled daily incremental run -- both idempotent,
both verified by running them back-to-back and confirming identical,
correct results.

**Delivery:** A live 7-page Streamlit dashboard (Executive Overview,
Readmission Analytics, Hospital Operations, Financial Performance,
Provider Performance, Patient Population, and a Data Quality page that
shows real pipeline health -- including one honest, unhidden failing
check), plus a fully specified Power BI implementation (data model, 39
DAX measures, page-by-page build guide) ready for a `.pbix` build.

**Testing & security:** 804 automated tests. Patient PII exclusion
enforced at three independent layers. All data is 100% synthetic,
generated by Synthea -- no real patient data is used anywhere in this
project.
